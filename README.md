# MAVI'S SHOP

Marketplace en español con Vite y Supabase, preparado para desplegar desde GitHub en Vercel.

**Comienza por [INSTRUCCIONES.md](INSTRUCCIONES.md).** Incluye la creación del administrador único, configuración de cuentas, base de datos, fotos, correos y despliegue.

```bash
npm ci
npm run dev
```

Sin variables de Supabase puedes recorrer la tienda vacía. No se simulan cuentas o ventas.

Logo e icono de pestaña: `public/logo.png`.

Para una instalación existente consulta ACTUALIZACION.md. Para conocer los servicios y pruebas pendientes consulta PUESTA-EN-MARCHA.md.
